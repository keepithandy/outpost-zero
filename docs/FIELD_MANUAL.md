# Field manual

## Mission

You lead Northstar Outpost on a hostile, nearly abandoned world. Build a stable settlement and activate **The First Beacon**. Every system operates within one continuous map and command deck—no disconnected gameplay tabs.

## First five minutes

1. Select **Ore Extractor** in Construct Modules and place it on an empty node. A brown ore node grants a 40% extraction bonus.
2. Place an **Arc Smelter** to refine scrap into alloy. Watch grid power and crew load.
3. Finish the first mission chapter for a resource grant. Add another hydroponic bay and a crew habitat.
4. Spend signal and alloy to research **Listening Protocol** and unlock the Deep-Space Uplink.
5. Launch **Wreck Salvage** expeditions to replenish scarce supplies. Research later upgrades, construct reactors, and complete all five chapters.

## Sector types

| Terrain | Benefit |
| --- | --- |
| Ore seam | +40% extractor output |
| Ice shelf | +35% hydroponic output |
| Solar dune | +20% solar output |
| Bare ground | Build any unlocked structure |
| Dead rift | Cannot build |

You cannot move the command core. All other structures may be demolished for a 40% refund of base construction materials.

## Resources and constraints

- **Scrap:** extracted from frontier geology and spent on construction or refined in smelters.
- **Alloy:** smelter output, structural material, and feedstock for advanced research.
- **Signal:** collected by uplinks and laboratories; spent on protocols and deep-space missions.
- **Rations:** generated by hydroponic bays, consumed by habitats and reactors, and spent on missions.
- **Grid power:** generated by the command core, solar arrays, and later reactors; automatically shared by all buildings.
- **Crew capacity:** provided by the command core and habitats. Work can continue below 100% efficiency when power or crew is scarce.

Structures can be upgraded to MK 3. Upgrading raises output; habitats also expand crew slots. Storms temporarily decrease solar power. Research and defensive structures mitigate these penalties.

## Expeditions

| Expedition | Unlock | Duration | Use |
| --- | --- | --- | --- |
| Wreck Salvage | Available immediately | 22 simulation seconds | Scrap and alloy |
| Void Survey | Listening Protocol | 38 simulation seconds | Signal and alloy |
| Deep Convoy | Helium Ignition | 56 simulation seconds | Bulk scrap and alloy |

Only one expedition can be active at a time. It completes as simulation time advances; speeds of 2× and 4× advance it correspondingly.

## Commands

| Input | Action |
| --- | --- |
| Click / tap a module, then a node | Construct a building |
| Click / tap a placed module | Open field inspector |
| Inspector → Upgrade | Pay materials to increase level |
| Inspector → Decommission | Remove module for partial refund |
| Space | Pause / resume |
| 1 / 2 / 3 | 1× / 2× / 4× simulation speed |
| Escape | Exit construction mode |
| Export / Import | Transfer a JSON save |
| New Expedition | Reset the current local save after confirmation |

## Persistence and offline play

A save is stored on this device in localStorage automatically every five simulation ticks, on visibility changes, and after player actions. Exports use plain JSON; no account or backend is involved. While away, a returning save can advance by **at most 15 minutes**.

The optional service worker caches a tiny application shell after the game has been opened on HTTPS or localhost. It does not change save location: clearing site data will erase local progression unless you exported a backup.

## Winning

Complete five chapters culminating in The First Beacon research and three operational uplinks. The outpost remains playable afterward; you can continue designing an efficient colony.
